# Focus Lock

A lightweight desktop application for Linux that helps you stay focused by blocking distracting applications.

## Features

- **Focus Mode**: Closes distracting applications and allows only user-defined resources.
- **Allowed Resources**: Add YouTube channels, applications, files, and folders to your whitelist.
- **Minimal, Dark-Mode UI**: Designed for simplicity and minimal distraction.

## Running Locally

To install and run:

```bash
./install_and_run.sh
```
